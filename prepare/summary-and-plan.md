# Heya Project Summary & Future Roadmap

## 1. Project Overview
**Heya** is a high-end, collaborative AI workspace designed for multi-agent brainstorming and problem-solving. It moves beyond simple 1-on-1 chat by allowing users to assemble a "team" of specialized AI agents that can interact with each other and the user in real-time.

### Core Identity
- **Mood**: Professional, precise, and innovative.
- **Visuals**: Vibrant orange branding, clean editorial typography, and smooth motion animations.

## 2. Current Feature Set (Completed)
- **Multi-Agent Orchestration**: Intelligent logic that selects the most relevant agent to respond based on conversation history.
- **Dynamic Workspaces**: Create and manage multiple discussion sessions with different agent combinations.
- **Agent Factory**: Create custom agents with specific roles, personalities, and AI-generated avatars.
- **Convergence Engine**: A system-level tool to summarize long discussions into actionable insights.
- **Integrated Documentation**: Comprehensive English guides built directly into the Settings menu.
- **Public Sharing**: One-click sharing functionality that generates public links for collaborative sessions.
- **Multi-Provider Support**: Backend support for Gemini, OpenAI, DeepSeek, Qwen, and xAI.
- **Scenario Mode**: Pre-configured dramatic or professional templates (e.g., "Love Battlefield").

## 3. Technical Stack
- **Frontend**: React 18, Tailwind CSS, Lucide React (Icons), Motion (Animations).
- **Backend**: Firebase Authentication (Google Login), Firestore (NoSQL Database).
- **AI Integration**: `@google/genai` for Gemini 3 series models.
- **Styling**: Modern "Editorial" design recipe with high-contrast typography and generous whitespace.

## 4. Next Steps & Roadmap

### Phase 1: Enhanced Interaction (Short Term)
- [ ] **Typing Indicators**: Show "Agent X is typing..." to make the collaboration feel more alive.
- [ ] **Message Actions**: Implement editing, deleting, and pinning of messages.
- [ ] **Mobile Optimization**: Refine the sidebar and chat layout for smaller touch devices.

### Phase 2: Advanced Capabilities (Mid Term)
- [ ] **Web Search Grounding**: Enable agents to use Google Search to provide real-time information.
- [ ] **Image Generation**: Integrate image generation tools so agents can "sketch" ideas.
- [ ] **File Attachments**: Allow users to upload documents for agents to analyze collectively.

### Phase 3: Social & Team Features (Long Term)
- [ ] **Presence Awareness**: See which friends are currently active in a shared session.
- [ ] **Threaded Discussions**: Support side-conversations to keep the main chat clean.
- [ ] **Workspace Roles**: Implement Admin/Editor/Viewer permissions for shared sessions.
